# Zezão Lanches Online

SITE DEMONSTRATIVO — ZEZÃO LANCHES



Crie um site demonstrativo profissional, moderno e totalmente funcional para o Zezão Lanches. O objetivo é apresentar uma proposta comercial ao estabelecimento, simulando um site pronto para receber pedidos online.



1. IDENTIDADE VISUAL



- Utilize a logo que enviarei à plataforma como identidade principal.

- Analise as cores da logo e aplique-as ao site.

- Não redesenhe, distorça ou modifique a logo.

- Crie uma identidade visual moderna, profissional e coerente.

- Utilize imagens genéricas de alta qualidade de hambúrgueres, batatas, bebidas e sobremesas.

- Não apresente produtos fictícios como se fossem o cardápio oficial.



2. HERO ANIMADO



Crie uma seção inicial de alto impacto, com:



- Imagem grande e apetitosa de um hambúrguer.

- Título: "SEU PRÓXIMO LANCHE FAVORITO ESTÁ AQUI!"

- Subtítulo convidando o visitante a conhecer o cardápio.

- Botão "FAZER PEDIDO".

- Botão "VER CARDÁPIO".

- Animações suaves de entrada, elementos flutuantes e efeitos de movimento.

- Animação visual no hambúrguer ou nos elementos decorativos.

- Fundo moderno, com contraste e ótima legibilidade.

5. CARRINHO FUNCIONAL



Implemente:



- Adicionar e remover produtos.

- Alterar quantidades.

- Mostrar adicionais selecionados.

- Calcular subtotal e total automaticamente.

- Exibir resumo do pedido.

- Permitir continuar comprando.

- Botão destacado "FINALIZAR PEDIDO".



Na finalização, solicitar:



- Nome do cliente.

- Tipo de entrega: retirada ou delivery.

- Endereço, quando for delivery.

- Forma de pagamento: Pix, dinheiro ou cartão.

- Observações do pedido.



Ao concluir, gerar uma mensagem organizada com produtos, quantidades, adicionais, endereço, pagamento e total, direcionando para o WhatsApp oficial informado abaixo.

8. DESIGN E EXPERIÊNCIA



- Layout responsivo para celular, tablet e computador.

- Prioridade para experiência mobile.

- Animações suaves durante a navegação.

- Cards modernos com bordas arredondadas.

- Efeitos hover discretos.

- Transições elegantes.

- Navegação intuitiva.

- Botões com feedback visual.

- Carregamento otimizado.

- Evitar aparência genérica de template.



9. REGRAS IMPORTANTES



- Este é um site demonstrativo para apresentação de proposta comercial, não uma confirmação de informações oficiais do estabelecimento.

- Utilizar a logo que será enviada como referência visual principal.

- Não inventar dados comerciais.

- Não deixar botões sem funcionalidade.

- Não implementar pagamentos reais.

- Não criar login ou cadastro desnecessário.

- Não adicionar funcionalidades não solicitadas.

- Manter o código organizado e evitar alterações desnecessárias.
